# 题库说明

`challenges.json` 是 Web 与微信小程序唯一的权威题库，`costs.json` 是成本审核清单，`sources.json` 保存来源登记。

- 所有金额单位均为人民币；账本显示的是“已列成本”，不是市场报价或法定费用。
- 用户已提供的数字进入题目，但在逐项终审前均保持 `pending_confirmation` 状态。
- 挂靠地址按白本 `¥1,300` 计入最低口径，同时展示红本 `¥1,800`。
- 等保二级 `¥50,000`、三级 `¥130,000` 来自文章注明的历史口径；当前价格和配套云安全资源仍待确认。
- 风险格是娱乐化游戏值，不是合规评级。
- 题目只提醒玩家核对适用边界，不替代法律、财税或安全专业意见。
- 修改题库后运行 `npm run sync:mini`，为小程序生成可加载的静态模块。
