# 一人公司生存模拟器

一个一屏一题的 25 题一人公司生存问卷。玩家可以继续承担成本，也可以随时退出并结算已经发生的费用、时间和待办。

Web 提供四个可独立访问的完整版本，四者共用同一份题库、可重放状态机、六类成本账本、五条时间轨道和结局，仅视觉与过关动效不同：

- `/minimal/`：SBTI 式极简，黑白冷灰、单题大字与进度线。
- `/paper/`：纸张账单 × 荒诞印章，以报销单、费用栏和红章强化成本感。
- `/cyber/`：极简赛博，以深色终端、数字脉冲和扫描放行表现闯关。
- `/pixel/`：像素 RPG × 办证地狱；25 题各有唯一的桌面/手机四态母板，选择后从本题动作切到完成或退出状态。

根路径 `/` 是无状态的版本选择页。项目同时提供原生微信小程序，Web 四个版本与小程序共用一份题库和同一套状态机。

像素版视觉源文件在 `design/characters/founder/` 与 `design/storyboards/`：包含人物母版、25 题场景 brief，以及记录 50 张双端母板尺寸、大小与 SHA-256 的 v2 清单。25 题条件路由与结算数据流见 `design/quiz-flow-v2.md`，账本、关键路径、分值和称号见 `design/settlement-v2.md`；相对最初原稿新增或替换的 9 题另列在 `design/quiz-new-questions-v2.md`，方便单独改文案。旧版 13 张分镜只作为画风参考，不参与新版完成度或运行时路由。运行时只读取仓库内的 WebP，不依赖远程图片。

## 零数据承诺

- 不提供登录、账号、排行榜、分享、历史记录或结果海报。
- Web 不使用 Cookie、Local/Session Storage、IndexedDB、网络请求、统计或错误上报。
- 小程序不调用登录、用户资料、网络请求、上传下载或 Storage API，并隐藏分享菜单。
- 答案和结果只存在当前运行内存中；刷新、关闭或重新进入即清空。
- 托管商或微信平台可能保留普通访问日志，但业务不会提交答案、账单或结局。

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev:web
```

Web 开发服务器默认监听 `http://127.0.0.1:5173`，对应入口为：

```text
http://127.0.0.1:5173/minimal/
http://127.0.0.1:5173/paper/
http://127.0.0.1:5173/cyber/
http://127.0.0.1:5173/pixel/
```

微信小程序直接用微信开发者工具打开仓库根目录；每次修改共享题库或核心逻辑后先执行：

```bash
npm run sync:mini
```

## 验证

```bash
npm run check
```

该命令依次执行两端类型检查、题库/状态机/账本/视觉资产测试、Web 静态构建以及源码/产物隐私扫描。Vite 会一次生成根选择页和四个独立 H5 目录，可直接放入同一个静态服务器目录。
