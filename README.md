# 一人公司生存模拟器

一个一屏一题的 12 关生存问卷。玩家可以继续承担成本，也可以随时退出并用不计分的围观模式查看后续难关。

Web 提供三个可独立访问的完整版本，三者共用同一份题库、状态机、三本账和结局，仅视觉与过关动效不同：

- `/minimal/`：SBTI 式极简，黑白冷灰、单题大字与进度线。
- `/paper/`：纸张账单 × 荒诞印章，以报销单、费用栏和红章强化成本感。
- `/cyber/`：极简赛博，以深色终端、数字脉冲和扫描放行表现闯关。

根路径 `/` 是无状态的版本选择页。项目同时提供原生微信小程序，Web 三个版本与小程序共用一份题库和同一套状态机。

## 零数据承诺

- 不提供登录、账号、排行榜、分享、历史记录或结果海报。
- Web 不使用 Cookie、Local/Session Storage、IndexedDB、网络请求、统计或错误上报。
- 小程序不调用登录、用户资料、网络请求、上传下载或 Storage API，并隐藏分享菜单。
- 答案和结果只存在当前运行内存中；刷新、关闭或重新进入即清空。
- 托管商或微信平台可能保留普通访问日志，但业务不会提交答案、账单或结局。

## 目录

```text

packages/game-core/      平台无关的状态机、计分与结局逻辑
web/                     Vite + Vanilla TypeScript 静态网页
miniprogram/             原生微信小程序（AppID: wx03f611286aacbfc4）
scripts/                 小程序同步生成与隐私扫描
tests/                   核心流程自动测试
research/                本地文章资料，不进入 Git
```

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev:web
```

Web 开发服务器默认监听 `http://127.0.0.1:5173`，对应入口为：

```text
http://127.0.0.1:5173/minimal/
http://127.0.0.1:5173/paper/
http://127.0.0.1:5173/cyber/
```

微信小程序直接用微信开发者工具打开仓库根目录；每次修改共享题库或核心逻辑后先执行：

```bash
npm run sync:mini
```

## 验证

```bash
npm run check
```

该命令依次执行两端类型检查、状态机与多入口测试、Web 静态构建以及源码/产物隐私扫描。Vite 会一次生成根选择页和三个独立 H5 目录，可直接放入同一个静态服务器目录。

## 成本口径

金额单位均为人民币。游戏显示的是用户提供或文章记录的“已列成本”，不是法定费用或实时市场报价。挂靠按白本 `¥1,300` 计入最低口径；等保按文章中的二级历史口径 `¥50,000` 计入，三级 `¥130,000` 仅展示为备选。所有数字仍需逐项最终确认，详见 `content/costs.json`。

本项目属于娱乐化个人经验，不构成法律、财税、安全或经营建议。
